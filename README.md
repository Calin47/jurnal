# Jurnal

Aplicatia publicata: **https://calin47.github.io/jurnal/**

Site static, fara server si fara build. **Datele stau doar in browserul tau**, in
`localStorage` - nu se trimit nicaieri si nu ajung pe GitHub. Cine deschide linkul
isi vede propriul jurnal, gol.

Backupul se face din aplicatie: pagina **Accounts**, cardul "Backup & transfer".
Fisierul exportat e singurul backup care exista.

Fisierele de aici sunt o copie publicata, actualizata din repo-ul sursa.
